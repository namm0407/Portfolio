Real time AI Object Detector using VLM

This project combines real-time object detection using YOLOv8 with a vision-language model (Qwen-VL) to create an interactive object detection and questioning system. When a specified object is detected in the webcam feed, the system captures an image and initiates a chatbot that can answer questions about the captured image.


Here is How It Works

1. User Input: You specify what object to detect (e.g., "car", "dog", "red cup")

2. Real-time Object Detection: The system uses YOLOv8 to continuously detects objects in real-time. Detected objects (non-target) are shown with green bounding boxes.

3. Image Capture: When the object is detected, an image of the scene is captured and automatically saved. Target object is highlighted with a red bounding box.

4. Vision-Language Model: The captured image is analyzed by the Qwen-VL model to understand its content and generates a description of the captured image

5. Question Answering: The system initiates a chatbot that can answer questions about the captured image
